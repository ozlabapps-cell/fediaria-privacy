Política de Privacidad de Fediaria

Última actualización: 2025

Fediaria es una aplicación cristiana creada para ofrecer versículos diarios, oraciones y contenido espiritual. Respetamos profundamente la privacidad de nuestros usuarios. Esta política explica qué información recopilamos, cómo se utiliza y cómo protegemos sus datos.

1. Información que NO recopilamos

Fediaria no recopila ningún dato personal, incluyendo pero no limitado a:

  • Nombre
  • Correo electrónico
  • Número de teléfono
  • Ubicación
  • Fotos o archivos
  • Contactos
  • Datos sensibles

2. Información recopilada automáticamente

Podemos recopilar información técnica no identificable para mejorar la app, como:

  • Versión del sistema operativo
  • Modelo del dispositivo
  • Datos anónimos de rendimiento
  • Errores de la aplicación

3. Anuncios

Fediaria puede mostrar anuncios mediante Google AdMob. Este servicio puede recopilar identificadores publicitarios no personales para personalizar anuncios. Puedes desactivar la personalización desde tu dispositivo Android en:

Configuración → Privacidad → Anuncios → Inhabilitar personalización de anuncios

4. Permisos

Fediaria utiliza únicamente los permisos necesarios para mostrar notificaciones. No solicita acceso a archivos, contactos, ubicación, cámara ni micrófono.

5. Servicios de terceros

Podemos utilizar servicios como:

  • Google AdMob - Para mostrar anuncios
  • Firebase Cloud Messaging - Para notificaciones (opcional)

6. Seguridad

No almacenamos datos personales de usuarios. No existe riesgo de filtración de información.

7. Niños

La app no está diseñada para niños menores de 13 años, aunque su contenido es apto para todo público.

8. Cambios en esta política

Podemos actualizar esta política en cualquier momento. Los cambios se publicarán en esta página.
